# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of `devwizardhq/wiz-captcha`.

| Version | Supported |
| --- | --- |
| Latest stable release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by emailing **syedshazeedul@gmail.com**.

To help us investigate quickly, include:

1. A clear description of the issue and its impact.
2. Steps to reproduce (proof of concept if possible).
3. The affected package version and environment details.

Please do **not** open a public GitHub issue for security reports.

We will acknowledge receipt as soon as possible, investigate promptly, and release a fix when confirmed.
